# Research & Experimentation Notebooks (`notebooks/`)

This directory contains Jupyter notebooks and Google Colab experiments for data analysis, model prototyping, and evaluation.

### Naming Convention:
`XX_<module_id>_<experiment_name>.ipynb`

Example:
- `01_02_academic_eda_and_feature_engineering.ipynb`
- `02_03_facenet_embedding_benchmark.ipynb`
- `03_05_yolov8_campus_surveillance.ipynb`
