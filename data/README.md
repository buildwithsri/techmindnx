# Data Directory (`data/`)

This directory is used for schemas, synthetic dataset generation scripts, and sample evaluation batches.

- `data/raw/`: Raw data feeds and unformatted samples (**ignored by Git**).
- `data/processed/`: Standardized feature tensors, data dictionaries, and schema definitions.

> **Note**: Never commit sensitive real student personally identifiable information (PII) or files larger than 50MB to Git.
